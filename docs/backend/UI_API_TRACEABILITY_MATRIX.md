# UI/API Traceability Matrix

The matrix records the production data source for each UI family. “Disabled” means the visible control has no mutation and explains why.

| UI screen/action                        | API endpoint(s)                                                                               | Scope/permission                                   | State                                             |
| --------------------------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------- |
| Login and startup restore               | `POST /auth/login`, `POST /auth/refresh`, `GET /auth/me`                                      | public/session                                     | Live                                              |
| Logout / change password                | `POST /auth/logout`, `POST /auth/change-password`                                             | current session                                    | Live                                              |
| All role dashboards                     | `GET /dashboard`                                                                              | `dashboard.read` + active-role scope               | Live                                              |
| Student schedule/announcements          | `GET /schedule`, `GET /announcements`                                                         | own enrollment/audience                            | Live                                              |
| Student course registration             | `GET /courses`, `POST /registrations`                                                         | `courses.read`, own submit                         | Live; full sections join waitlist on finalization |
| Student current courses/drop            | `GET /courses/mine`, `POST /registrations/enrollments/{id}/drop`                              | own enrollment                                     | Live                                              |
| Student grades/appeal                   | `GET /grades/transcript`, `POST /grades/appeals`                                              | own published grades                               | Live                                              |
| Student attendance                      | `GET /attendance/summary`                                                                     | own record                                         | Live                                              |
| Student transcript download             | `GET /grades/transcript` then browser print/save                                              | own record                                         | Live, explicitly unofficial                       |
| Instructor classes/schedule             | `GET /courses/mine`, `GET /schedule`                                                          | assigned sections                                  | Live                                              |
| Instructor attendance                   | `GET /attendance/sections`, `GET .../roster`, `POST /attendance/sessions`, `POST .../records` | assigned sections                                  | Live                                              |
| Instructor gradebook                    | `GET /grades/sections/{id}`, `POST /grades/assessments`, `POST .../scores`, `POST .../submit` | assigned sections                                  | Live                                              |
| Instructor announcements                | `GET/POST /announcements`                                                                     | assigned section audiences                         | Live                                              |
| Advisor advisees                        | `GET /students`                                                                               | active advisor assignments                         | Live                                              |
| Advisor approvals                       | `GET /registrations/pending`, `PATCH /registrations/{id}/decision`                            | assigned advisees                                  | Live                                              |
| Registrar monitoring/finalize           | `GET /registrations/pending`, `POST /registrations/{id}/finalize`                             | registration office                                | Live                                              |
| Registrar course/student lists          | `GET /courses`, `GET /students`                                                               | granted institution scope                          | Live                                              |
| Department grade approval               | `GET /grades/submissions/pending`, `POST .../publish`, `POST .../return`                      | department scope                                   | Live                                              |
| Department schedule/staff               | `GET /schedule`, `GET /staff`                                                                 | department scope                                   | Live                                              |
| Coordinator curriculum/progress         | `GET /curriculum`, `GET /students`                                                            | program scope                                      | Live                                              |
| Dean dashboard/analytics/planning       | `GET /dashboard`, `GET /analytics`, `GET /staff`                                              | faculty scope                                      | Live/read-only                                    |
| University registrar students/terms     | `GET /students`, `GET /terms`                                                                 | institution permission                             | Live                                              |
| Role report screens                     | `GET /reports`, `GET /reports/{key}/export`                                                   | own/advisor/program/department/faculty/institution | Live                                              |
| Admin users/role counts                 | `GET /users`                                                                                  | `users.read`                                       | Live                                              |
| Admin audit                             | `GET /audit`                                                                                  | `audit.read`                                       | Live; export disabled                             |
| Admin settings                          | `GET /settings`, `PUT /settings/{key}`                                                        | `settings.read/manage`                             | Live                                              |
| Profile display                         | authenticated `GET /auth/me` state                                                            | own identity                                       | Live                                              |
| Profile edit                            | backend `PATCH /profile` exists                                                               | `profile.update`                                   | UI disabled pending approved field form           |
| Create user/student/course/term/section | backend endpoints exist                                                                       | management permissions                             | UI wizards disabled                               |
| Role assignment                         | `PUT /users/{id}/roles` exists                                                                | `roles.manage`; self-change denied                 | UI disabled pending scoped assignment wizard      |
| Syllabus upload                         | none                                                                                          | storage/retention contract unapproved              | Disabled                                          |

Query/mutation code lives in `src/api/`; screen consumption lives in `src/screens/`. No screen imports academic mock arrays.
